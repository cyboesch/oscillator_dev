Liberation Sans 2.1.5

Unmodified TrueType files from the official Liberation Fonts 2.1.5 release.
The family is metrically compatible with Arial. No system installation is needed.
Register the required faces with matplotlib.font_manager.fontManager.addfont(path)
and select family "Liberation Sans". Use pdf.fonttype=42 for embedded TrueType.
